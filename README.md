## Changelong Component
A simple, responsive and visually clean <b> Changelong Component </b> built using <b> HTML and CSS </b>
This project demonstrates layout techniques, positioning, and timeline UI patterns commonly used in modern web interfaces

## Project Details
This component displays a vertical timeline of updates, with alternating left–right alignment for each entry.
It includes:
<li>A centered vertical timeline</li>
<li>Dots marking each update</li>
<li>Alternating left–right content alignment</li>
<li>Clean and semantic HTML structure</li>
<li>Fully responsive layout for mobile screens</li>
<li>Modern UI styling with spacing, shadows, and typography</li>
